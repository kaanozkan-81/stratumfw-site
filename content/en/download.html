Release Notes

What's new in v0.34.2

  • OpenSSL Key Generation (v0.34.2): WireGuard / Curve25519 helper key generation migrated to OpenSSL via the Python cryptography library; Stratum FW implements zero custom cryptography of its own.
  • Site-to-Site IPsec (IKEv2 & IKEv1 with kernel ESP enc0) and dedicated WireGuard S2S (wg1+) tunnels for FortiGate, Cisco, MikroTik RouterOS 7 & cloud VPCs (v0.33.0 – v0.34.1).
  • 30-day Inter-VLAN Traffic Matrix (Diagnostics > Firewall Log > Between networks, including IPsec & WireGuard S2S flows) for VLAN segmentation (v0.32.0).
  • Hitless OS updates & Suricata restarts with zero igb/netmap WAN port flaps, post-update Apply alerts, and a softer Light Theme (v0.31.2 – v0.31.6).
  • All / Default / Custom rule views, pfSense-style coloured separators, TOTP 2FA, and HTTPS-only Secure session cookies (v0.30.0 – v0.31.3).
  • Direct OPNsense config.xml, OpenVPN PKI, Unbound DNSBL, and full-span DHCP pool migration plus Force DNS for Active Directory (v0.27.1 – v0.30.5).

Source Availability & Licensing

Stratum Firewall is built on audited open-source foundations (FreeBSD 15.1, pf, OpenZFS, Suricata, Unbound, WireGuard, strongSwan) and is distributed completely free ($0/year, zero tunnel or user limits). Core FastAPI panel sources remain in a private repository during pre-v1.0 development, while documentation, changelogs, and issue tracking are public on GitHub.
