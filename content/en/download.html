Before you download

Verify the integrity of the installer after downloading by comparing its SHA-256 hash to the values shown in each variant below.

On Linux or macOS:

sha256sum stratum-fw-0.27.1-amd64.*

On Windows (PowerShell):

Get-FileHash .\stratum-fw-0.27.1-amd64.* -Algorithm SHA256

Release Notes

What's new in v0.27.1

  • Drop-in OPNsense configuration (config.xml) and complete OpenVPN server migration with unchanged client profiles
  • Virtual IPs (Interfaces > Virtual IPs) and Static Routes (Interfaces > Routes) managed cleanly via stratum-netextra
  • Dynamic Hostname aliases and license-free Country (GeoIP) aliases from the 5 Regional Internet Registries
  • Built-in Wireshark Packet Capture (.pcap), ARP Table with Wake-on-LAN, and Remote-Safe Factory Reset
  • Per-interface dual-engine Suricata IPS/IDS (Watch & Block modes) and 55-category DNSBL Web Filter
  • Read the full release history in the Changelog
