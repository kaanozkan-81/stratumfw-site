Before you download

Verify the integrity of the ISO or IMG file after downloading by comparing its SHA-256 hash to the values shown in each variant below.

On Linux or macOS:

sha256sum stratum-fw-v0.24.2-*

On Windows (PowerShell):

Get-FileHash .\stratum-fw-v0.24.2-* -Algorithm SHA256

Release Notes

What's new in v0.24.2

  • Complete architectural rewrite based on FreeBSD 14
  • Both bootable ISO (.iso) and USB flash drive disk images (.img) provided
  • Native pf packet filter for wire-speed stateful inspection and ALTQ shaping
  • Modern asynchronous Python 3.12 & FastAPI management panel and REST API
  • Zero-dependency WireGuard VPN integration (native RFC 7748 X25519)
  • DNSBL Web Filtering & automated Threat Intelligence IP Blocklists
  • Role-Based Access Control (Admin, Operator, Read-Only) & Safe-Apply rollback workflow
