Before you download

Verify the integrity of the ISO after downloading by comparing its SHA-256 hash to the values shown in each variant below.

On Linux or macOS:

sha256sum stratum-fw-v0.8.0-*.iso

On Windows (PowerShell):

Get-FileHash .\stratum-fw-v0.8.0-*.iso -Algorithm SHA256

Both images install the identical FreeBSD-based gateway. Pick the one that matches how you'll access the installation console.

Release Notes

What's new in v0.8.0 (Beta)

  • Complete architectural rewrite based on FreeBSD 14
  • Native pf packet filter for wire-speed routing
  • Modern FastAPI management panel
  • Zero-dependency WireGuard VPN integration (X25519)
  • Role-Based Access Control (Admin, Operator, Read-Only)
  • Safe-Apply configuration workflow (automatic rollback)
