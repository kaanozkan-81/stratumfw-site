Before you download

Verify the integrity of the ISO after downloading by comparing its SHA-256 hash to the value shown in each variant below.

On Linux or macOS:

sha256sum stratum-gateway-installer-*.iso

On Windows (PowerShell):

Get-FileHash .\stratum-gateway-installer-*.iso -Algorithm SHA256

What's new in this release

Highlights from the current installer.

BIOS and UEFI boot

The installer now boots on both legacy BIOS and modern UEFI firmware. No BIOS configuration change required for UEFI-only systems.

VGA and Serial console variants

Two separate images — one for physical displays, one for serial-over-LAN consoles used in headless data centers.

Predictable first-login credentials

The initial username and password follow a documented, pfSense-style convention. Read them from the installation summary on first login.

Mandatory password change

Until you change the initial password, the rest of the panel remains locked. No configuration change is possible before this step.

Before you install

A few things worth knowing so your deployment starts on the right foot.

Minimum requirements

  • 64-bit x86-64 CPU (2 cores minimum, 4 recommended)
  • 2 GB RAM minimum, 4 GB recommended
  • 8 GB storage minimum, 20 GB recommended
  • Two network interfaces (WAN + LAN minimum)

Deployment targets

  • Bare-metal appliance (recommended for production)
  • KVM, VMware, Proxmox, VirtualBox, Hyper-V
  • Cloud instances supporting custom ISO boot
  • USB-bootable installation media (Rufus recommended)

What's included

  • Debian 13 (trixie) base system
  • All 26 Stratum Gateway modules
  • Web management panel and API
  • Built-in certificate authority
  • Update mechanism (connects to update.stratumfw.com)

What you'll need

  • An empty USB stick (2 GB+) or VM to boot from
  • Basic network information: gateway IP, DNS, DHCP ranges
  • About 15–20 minutes for a fresh installation
  • Physical or serial console access on first boot
