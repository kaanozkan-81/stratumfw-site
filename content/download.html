Build from Source

The FreeBSD installer ISO is not yet publicly available. However, you can deploy the management panel and configuration engine on an existing FreeBSD 14 system.

Prerequisites:

FreeBSD 14.1+
Python 3.12+
pf enabled

Clone the repository:

git clone https://github.com/kaanozkan-81/stratumfw-site.git
cd stratumfw-site

Note: The source code for the panel itself is maintained in a private repository. Public access to the core engine and FreeBSD configurations will be provided upon v1.0.0 release.

System Requirements

What you need to run Stratum Gateway.

Minimum

  • 64-bit x86-64 CPU
  • 2 GB RAM
  • 8 GB Storage
  • 2 Network Interfaces (WAN + LAN)

Recommended

  • 4+ Cores CPU
  • 4 GB+ RAM
  • 20 GB+ SSD Storage
  • Intel/AMD NICs (for best pf performance)
