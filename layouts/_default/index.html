NETWORK TOPOLOGY & VLAN SEGMENTATION

Complete Network Isolation with Multi-VLAN Segmentation

Manage physical network interfaces and virtual LANs (VLANs) from a unified control plane to securely isolate office workstations, guest Wi-Fi, staff devices, and IoT traffic.

Stratum Firewall provides a flexible multi-interface networking architecture designed to simplify complex network topologies. Administrators can map physical interfaces (pppoe0 WAN, igb1 LAN, igb2 OPT1, igb3 OPT2) and carve out logically isolated VLAN segments—such as Office LAN, Guest Wi-Fi, Staff, and Security Cameras—over shared physical infrastructure. With built-in DHCP Server, DNS Resolver, and NTP time synchronization services, each network zone operates with its own dedicated addressing and routing policies.

  • ✓ Multi-Interface & WAN Mapping: Configure dedicated WAN, LAN, and optional (OPT1/OPT2) interfaces with native PPPoE and static/dynamic IP support.
  • ✓ Granular VLAN Segmentation: Separate untrusted IoT devices and guest wireless clients from core infrastructure to prevent lateral movement.
  • ✓ Integrated Core Network Services: Run dedicated DHCP scopes, local DNS resolution, and NTP services seamlessly across every network segment.
KERNEL-LEVEL PF PACKET FILTER

Uncompromising Network Shield with Native FreeBSD pf Filtering

Powered directly by the FreeBSD 14/15 kernel pf engine, delivering wire-speed stateful packet inspection, ALTQ traffic shaping, and fail-safe rule validation.

At the core of Stratum Firewall lies FreeBSD's battle-tested kernel-level pf (Packet Filter) engine. Every network packet is inspected against active connection states at the kernel layer, neutralizing unauthorized access attempts while forwarding legitimate traffic with minimal latency. Integrated Network Address Translation (NAT) and ALTQ bandwidth shaping keep critical applications responsive under heavy load. Before any configuration change goes live, the Safe-Apply engine automatically validates rules against pf syntax to prevent accidental lockouts or broken rulesets.

  • ✓ Native Kernel Stateful Inspection: High-throughput packet filtering powered directly by FreeBSD 14/15 pf without user-space bottlenecks.
  • ✓ Safe-Apply Syntax Validation: Pre-flight verification of all firewall rules and interface updates before committing changes to the active kernel.
  • ✓ NAT, ALTQ & Real-Time Rule Hits: Manage reusable Aliases, Pass / Block / Reject policies, live rule hit counters, and ALTQ traffic prioritization in one place.
THREAT INTELLIGENCE & DNSBL

Proactive Web Filtering (DNSBL) and Automated IP Blocklists

Neutralize malicious domains and known attacker IPs before they ever reach your endpoints using DNS-level sinkholing and automated threat intelligence feeds.

Stratum Firewall extends packet filtering with multi-layered threat intelligence. The IP Blocklists module ingests external threat feeds to drop traffic from known command-and-control servers, scanners, and malicious hosts directly at the packet level. Simultaneously, DNS-Based Web Filtering (DNSBL) intercepts requests to phishing, malware, and tracking domains at the DNS resolution layer—returning an immediate NXDOMAIN response across all network devices without requiring client-side agents. An integrated domain lookup utility lets administrators test and verify domain blocking status in real time.

  • ✓ Network-Wide DNS Sinkholing (DNSBL): Block malicious, phishing, and unwanted domains at the DNS layer by returning NXDOMAIN responses.
  • ✓ Automated Threat Feed IP Blocking: Import curated IP blocklists to automatically drop packets from hostile networks at the perimeter.
  • ✓ Instant Domain Lookup Diagnostic: Test whether specific domains are permitted or blocked directly from the web dashboard in real time.
MODERN ARCHITECTURE & API CONTROL

Zero-Dependency Cybersecurity Architecture with Modern API Control

"Raw FreeBSD power. Modern API control." Experience a lightweight Python 3.12 & FastAPI backend, declarative config.json state management, and native WireGuard cryptography.

Engineered to replace bloated legacy firewall appliances, Stratum Firewall pairs raw FreeBSD kernel performance with a clean, developer-first control plane. Its asynchronous Python 3.12 and FastAPI backend delivers both a responsive web UI and a full-featured REST API with a minimal memory footprint. The entire appliance state resides in a single declarative config.json file, which the core engine dynamically compiles into native pf.conf, DHCP, and DNS configurations. Complete with zero-dependency native X25519 (RFC 7748) WireGuard VPN and OpenVPN support, Role-Based Access Control (RBAC), and real-time hardware and firewall log telemetry, it brings modern infrastructure-as-code simplicity to network security.

  • ✓ FastAPI & Declarative config.json Engine: Manage the entire firewall state through a single JSON source of truth and automate workflows via a complete REST API.
  • ✓ Zero-Dependency WireGuard & OpenVPN: Built-in RFC 7748 X25519 cryptographic key generation for WireGuard alongside flexible OpenVPN tunneling.
  • ✓ RBAC & Real-Time System Telemetry: Granular Administrator, Operator, and Read-Only roles paired with live CPU, memory, disk, thermal, traffic, and firewall log dashboards.
