Core Capabilities

Engineered for absolute control

Stratum Firewall combines the battle-tested pf packet filter with a lightning-fast FastAPI management panel. Zero proprietary dependencies, absolute control, and a security-first architecture built for modern infrastructure.

pf Packet Filter

Stateful packet filtering and NAT in the FreeBSD kernel pf engine, with per-network and per-host bandwidth limits applied via dummynet alongside pf.

Multi-Vendor S2S & Remote VPN

Site-to-Site IPsec (IKEv2/IKEv1, strongSwan) and FreeBSD kernel WireGuard tunnels to FortiGate, MikroTik RouterOS 7, pfSense/OPNsense, Cisco, and cloud gateways. Keys are generated with OpenSSL (Python cryptography); Stratum implements no custom cryptography.

Declarative Config

A single config.json drives the entire system. Our Python engine dynamically renders your pf.conf, DHCP, and DNS files with absolute precision.

FastAPI Backend

A fully asynchronous Python backend. The panel serves as a lightweight, high-performance REST API and UI, keeping memory footprint to an absolute minimum.

Role-Based Access

Enterprise-grade RBAC out of the box. Differentiate between Administrators, Operators, and Read-Only users across every API and interface.

IP & DNS Blocklists

Protect your network at both layers. Ingest public threat feeds to block malicious IPs at the packet level, while simultaneously dropping malicious domains via DNSBL.

Why Stratum

Safe-Apply Architecture

Every change is checked before it is applied (pf, nginx, DNS, and SSH configuration tests). If you do not confirm it within the 60-second timeout, it is rolled back automatically so a mistake cannot lock you out.

02

Zero Vendor Lock-in

Import your existing OPNsense configuration (interfaces, VLANs, rules, NAT, aliases, DHCP, OpenVPN users, DNS blocklists). Runs on your own hardware with zero subscriptions, no cloud account, and no outbound telemetry.

03

Clean & Auditable

The generated configuration files are human-readable. Inspect your pf.conf and wg0.conf at any time. What you see is exactly what the kernel runs.
