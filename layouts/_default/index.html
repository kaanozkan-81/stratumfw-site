Core Capabilities

Engineered for absolute control

Stratum Firewall combines the battle-tested pf packet filter with a lightning-fast FastAPI management panel. Zero proprietary dependencies, absolute control, and a security-first architecture built for modern infrastructure.

pf Packet Filter

Powered by FreeBSD's native firewall. Stateful inspection, NAT, traffic shaping (ALTQ), and maximum throughput at kernel level.

Zero-Dependency VPN

Native WireGuard implementation. We wrote the X25519 cryptography from scratch (RFC 7748) so you don't need external dependencies to secure your tunnels.

Declarative Config

A single config.json drives the entire system. Our Python engine dynamically renders your pf.conf, DHCP, and DNS files with absolute precision.

FastAPI Backend

A fully asynchronous Python backend. The panel serves as a lightweight, high-performance REST API and UI, keeping memory footprint to an absolute minimum.

Role-Based Access

Enterprise-grade RBAC out of the box. Differentiate between Administrators, Operators, and Read-Only users across every API and interface.

IP & DNS Blocklists

Protect your network at both layers. Ingest public threat feeds to block malicious IPs at the packet level, while simultaneously dropping malicious domains via DNSBL.

Production Deployment & Lifecycle

Deploy on bare-metal or hypervisors in minutes

Stratum Firewall ships as a self-contained FreeBSD 15.1-RELEASE appliance OS with fully offline OpenZFS installers for monitor/keyboard rigs (VGA ISO) and headless serial hardware (115200 8N1 IMG). Whether you are importing an existing OPNsense gateway, linking branches over IPsec and WireGuard S2S, or running on Proxmox VE, KVM, and VMware ESXi, every change and update is engineered against remote lockouts.

  • ✓
    Offline OpenZFS Installers & Boot Environments: Installs directly onto ZFS; every signed online update or air-gapped .sfu bundle snapshots a new boot environment so previous versions remain one reboot away.
  • ✓
    Declarative JSON & 60s Safe-Apply: Replaces fragile PHP/XML files with a single auditable config.json (isolating VPN and 2FA keys in 0600 root-only files) and automatically reverts unconfirmed changes.
  • ✓
    Full Enterprise Routing, VPN & DPI: Multi-vendor IPsec (IKEv2/IKEv1), dedicated WireGuard S2S (wg1+), OpenVPN, dual-engine Suricata 8 IPS/IDS, 55-category Web Filter, and 30-day inter-VLAN traffic matrix.
  • ✓
    Encrypted SFTP Backups & Read-Only MCP: Scheduled AES-256-GCM (.stbk) backups including all PKI/certificates, plus an optional 14-tool read-only MCP server for safe AI diagnostics.
