Core Capabilities

Engineered for absolute control

Stratum Firewall combines the battle-tested pf packet filter with a lightning-fast FastAPI management panel. Zero proprietary dependencies, absolute control, and a security-first architecture built for modern infrastructure.

pf Packet Filter

Powered by FreeBSD's native firewall. Stateful inspection, NAT, traffic shaping (ALTQ), and maximum throughput at kernel level.

Zero-Dependency VPN

Native WireGuard implementation. We wrote the X25519 cryptography from scratch (RFC 7748) so you don't need external dependencies to secure your tunnels.

Declarative Config

A single config.json drives the entire system. Our Python engine dynamically renders your pf.conf, DHCP, and DNS files with absolute precision.

FastAPI Backend

A fully asynchronous Python backend. The panel serves as a lightweight, high-performance REST API and UI, keeping memory footprint to an absolute minimum.

Role-Based Access

Enterprise-grade RBAC out of the box. Differentiate between Administrators, Operators, and Read-Only users across every API and interface.

IP & DNS Blocklists

Protect your network at both layers. Ingest public threat feeds to block malicious IPs at the packet level, while simultaneously dropping malicious domains via DNSBL.
